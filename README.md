# Password-strength-lab

Password Strength Lab is an educational cybersecurity project designed to analyze password strength and demonstrate different password-cracking strategies.

The project combines local password analysis with brute-force and dictionary-based approaches to illustrate why password length, complexity, common patterns, personal information, and password reuse can affect password security.

The goal is not to crack real accounts, but to raise awareness of password security through practical and controlled experiments.

## Features

- Password strength analysis
- Detection of common password patterns
- Detection of repeated characters and patterns
- Simple brute-force demonstration
- Dictionary-based brute-force demonstration
- Breached email checking
- Educational demonstrations of password security concepts
